# FarmSolver

Расчётный планировщик Stardew Valley 1.6.15: 69 видов семян и саженцев всех сезонов, календарь роста, графики прибыли, переработка, кулинарные рецепты и подключаемые наборы модов.

Из папки `demo`: `npm run dev`, затем открыть http://127.0.0.1:4173. Установка зависимостей не нужна. Проверка расчётной модели: `npm test`.

Первичные данные отделены от расчётов. Прибыль и производные цены вычисляются; исключения с фиксированными игровыми ценами заданы правилами рецептов. Наборы модов подключаются JSON-файлами во вкладке «Моды»; поддерживаются фильтры сезона, повторного сбора, категории и набора. Это формат FarmSolver, а не прямой импорт файлов игровых модов.

Подробности: [архитектура](demo/ARCHITECTURE.md), [пример набора](demo/dist/packs/example.json), [схема](demo/dist/packs/schema.json). Все допущения доступны в интерфейсе во вкладке «Формулы».

Сравниваются монопосевы с бюджетом на весь период. Смешанные оптимальные планы, реинвестирование и расписание загрузки оборудования пока не моделируются. Пунктир графиков показывает потенциальную стоимость переработки, а не деньги в день урожая.
